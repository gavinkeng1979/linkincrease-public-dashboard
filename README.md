# Linkincrease Customer Dashboard

Public viewer for the Linkincrease customer dashboard.

The page is protected by a password and the dashboard data is stored as an encrypted browser payload. The private source repository remains the source of truth; do not commit plaintext customer data to this repository.

Open the published page at <https://gavinkeng1979.github.io/linkincrease-public-dashboard/>, enter the shared access password, and use the coverage strip, compact KPI cards, customer source and regional distribution, eight-day outreach trend, four-column pipeline, action queue, and lead details to review the current customer state.
